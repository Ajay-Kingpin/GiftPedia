# GiftPedia Streamlit Deployment Guide

## 🚀 Deploy to Streamlit Cloud

### **✅ Quick Deployment**

#### **Step 1: Create Streamlit Account**
1. Go to [Streamlit Cloud](https://streamlit.io/cloud)
2. Click "Sign up" and create an account
3. Connect your GitHub account

#### **Step 2: Deploy Your App**
1. Click "New app" in Streamlit Cloud
2. Select GitHub repository: `Ajay-Kingpin/GiftPedia`
3. Configure deployment settings:
   - **Main file path:** `streamlit_app.py`
   - **Python version:** `3.9` or higher
   - **Requirements file:** `requirements.txt`

#### **Step 3: Environment Variables (Optional)**
Add these environment variables if needed:
- `GEMINI_API_KEY`: Your Gemini API key
- `AMAZON_ASSOCIATE_TAG`: Your Amazon affiliate tag

#### **Step 4: Deploy**
Click "Deploy" and wait for the deployment to complete
